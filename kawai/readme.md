# Кавай — наш «слон»

Почему НБА разгромила «Клипперс», не тронула «Вашингтон» и пока ничего не делает с «Милуоки».

- `kawai.odt` — текст статьи со встроенными картинками.
- `cover_mammoths.jpg` — обложка: фото Chensiyuan (Wikimedia Commons, CC BY-SA 4.0), надпись на майке изменена скриптом `cover_mammoths.py`; производная работа под той же лицензией.
- `chart6_metanorm.png`, `chart8_comic.png`, `chart2_money_loop.png`, `chart7_silver_reach.png` — схемы.
- `kawai_diagrams.py` — строит схемы (matplotlib); пути рассчитаны на раскладку исходного репозитория (`../data/`, `../charts/`).
- `cover_mammoths.py` — строит обложку из исходного фото: `python cover_mammoths.py <фото.jpg>`.
